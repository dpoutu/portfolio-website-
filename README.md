# Portfolio Website

A modern, responsive portfolio website showcasing your skills, projects, and contact information.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Interactive Navigation**: Mobile-friendly hamburger menu with smooth scrolling
- **Sections Include**:
  - Hero/Landing section with call-to-action
  - About Me section
  - Skills showcase with cards
  - Projects gallery
  - Contact information with social links

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize the content with your own information:
   - Update personal information in `index.html`
   - Modify colors and styling in `styles.css`
   - Add your own projects and links

## Customization

### Updating Content
- Edit `index.html` to change text, links, and structure
- Replace "Your Name" with your actual name
- Update email and social media links in the Contact section
- Add your own project details and links

### Styling
- Modify CSS variables in `styles.css` to change colors:
  - `--primary-color`: Main theme color
  - `--secondary-color`: Accent color
  - Other variables for text and backgrounds

### Adding Projects
Add new project cards in the Projects section of `index.html` following the existing structure.

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript

## Browser Support

This website works in all modern browsers including:
- Chrome
- Firefox
- Safari
- Edge
